# Project - 4   Functional Treat

###  Introduction
Data Analyzer and Transformer is a Python project developed to practice and strengthen important Python programming concepts through data analysis and transformation operations.

It allows users to input a 1D dataset and perform various operations such as displaying data summaries, calculating factorials using recursion, filtering data using lambda functions, sorting data, and displaying dataset statistics.

###  Features

- Input and store dataset
- Display data summary and statistics
- Calculate factorial using recursion
- Filter data using lambda function
- Sort data in ascending or descending order
- Menu-driven program with input validation
